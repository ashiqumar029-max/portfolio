# Umar — Developer Portfolio

A responsive, dark-themed portfolio website made with plain HTML, JavaScript, and dynamically injected CSS. No build tools or package installation are required.

## Files

- `index.html` — page structure and portfolio content
- `style.js` — portfolio styling (creates a CSS style element)
- `script.js` — mobile navigation, current year, email link, and section reveal
- `README.md` — setup and publishing instructions

## Run locally

1. Download and extract the portfolio files.
2. Open `index.html` in a modern browser.
3. Edit the placeholder content before publishing.

## Personalize before uploading

1. In `index.html`, update the name, intro, About section, project names, descriptions, technology tags, and GitHub links.
2. Replace the `https://github.com/` links with your profile and repository URLs.
3. In `script.js`, replace `your.email@example.com` with your real contact email.
4. Update the skills so they accurately reflect your experience.
5. The design loads Manrope and DM Mono from Google Fonts; system fallback fonts are used if they are unavailable.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `my-portfolio`.
2. Upload `index.html`, `style.js`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Notes

- This is a static site; it does not require a server or API key.
- `style.js` is intentionally used because it was requested. It injects the stylesheet into the page at runtime.
- Project cards are examples. Replace them with your actual work before sharing the portfolio.
