# AM/DEV — Portfolio Website 01

A responsive creative developer portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and project sections
- `style.css` — responsive dark editorial design
- `script.js` — mobile navigation, current year, and scroll reveals

## Run locally
1. Keep all three files in the same folder.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Replace Alex Morgan, `hello@example.com`, social links, project descriptions, and placeholder projects with your own details.

## Notes
Google Fonts are loaded online. The project visuals are created with CSS, so no image assets are required.
