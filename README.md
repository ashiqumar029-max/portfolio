# Digital Craft — Portfolio

A responsive, dark-themed portfolio built with plain HTML, CSS, and JavaScript. No build tools or frameworks are required.

## Files
- `index.html` — page content and structure
- `styles.css` — layout, responsive styles, animations, and project mockups
- `script.js` — mobile navigation, project filters, and current year

## Preview locally
Open `index.html` in a browser. For the best local development experience, use VS Code's Live Server extension.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example, `portfolio`).
2. Upload all four files in this folder to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two; GitHub will show your live website URL in the Pages section.

## Before publishing
- The portfolio intentionally does not include a personal name.
- In `index.html`, replace `hello@example.com` in the contact link with the email address you want visitors to use. This is a placeholder until you replace it.
- Project cards are concept concepts/mockups, not claims of completed client work. Keep the note visible or replace the projects with your real work.
- The Google Fonts import requires an internet connection; the page otherwise works without a build step.
